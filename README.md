# Yana Imagine — релизы

Здесь лежат только установщики и обновления. Код — в приватном репозитории.

- **Yana Imagine** — `YanaImagine-Setup-<версия>.exe`
- **Imagine Host** — `ImagineHost-Setup-<версия>.exe`

Свежая версия — в [Releases](https://github.com/Zelyutin-Releases/YanaImagine/releases/latest). Установленные приложения обновляются сами, в фоне.

Каждый установщик подписан ключом Ed25519 (файл `.sig` рядом). Приложение ставит обновление, только если подпись сходится с ключом, зашитым в него.
